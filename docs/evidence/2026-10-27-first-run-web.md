# 新用户前端入口：免费模板与显式模型配置

阶段：个人 Beta，MF-P01/P13/P18/P20/P21。原前端基线 `ec2ff5b`，
本地主线在安装 / CI 提交 `93f483b` 后独立接入。没有部署、启停服务、
调用模型或修改用户作品；本文不包含私人配置、作品或原始日志。

## 本批行为

- 空作品页提供无 Key 模板 / 审核曲库起点，以及模型配置入口。
- 设置页说明如何获取自己的 Key，复用终端配置和既有运行态读取，
  不接收 / 显示 Key，不推断私有文件是否存在，不自动测试连接。
- Brief 读取运行配置；未知 / 读取失败先要求重读，保留已填内容。
  `not_configured` 可明确选择“使用免费模板规划”；已配置则保留描述
  发送与可能计费提示，不以连接测试成功作为提交条件。
- 确定性模板不理解任意自然语言，计划仍需人工审批；钢琴按描述修改
  是另一条模型专属路径，无 Key 时继续禁用并指向设置。
- 同页未确认提交保留 body / 请求 Key；相同内容手动重试复用身份。
  改内容先要求核对已有任务，确定的422校验拒绝可更正后新提交。
  离页迟到回执不会导航到别的作品。此保护不跨刷新 / 离开持久化。

API 没有客户端强制免费模式字段：提示反映读取到的运行配置，不是请求级
模式锁定。服务重新配置后应刷新；本批没有新增后端协议或非法零预算请求。
