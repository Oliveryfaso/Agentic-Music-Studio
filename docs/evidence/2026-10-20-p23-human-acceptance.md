# Motif 统一人工验收

验收顺序：听感 → 保存版播放 → 三曲来源/界面。人工结论仍待填写；机器测试不能替代。

1. 使用本任务交付的限时本机入口，先播放A原基线，再在同一秒切B中频−12dB、C旁路。共用音量、原始媒体，不分别响度归一化。记录设备/浏览器与“明显、不明显、不确定”；B更轻本身不是音色结论。
2. 打开入口的实际Studio构建，检查保存版Revision编号、播放/暂停/停止归零、静态音频与EQ草稿说明。此入口使用明示只读保留快照，禁止保存/生成，不连接用户数据库。
3. 查看C01小步舞曲16bars3/4 G、C02坦诉8bars4/4 C、J01 Bethena8bars3/4 G；每曲另有尾音释放小节。新增三和弦不还原完整原谱和声。C01省装饰、C02无原左手/力度演奏、J01只取第9–16小节且不加swing，入口逐曲披露。
4. 在入口填写实际反馈并下载文本，再交回。页面不自动上传。后续按真实反馈改进，不默认“人耳通过”。

入口不是生产API/PG/Worker全链；三曲picker、语义v2/0030未实现，不能据快照视图验收三曲导入→自然语言→保留/撤销。该完整用户链路待后续实现与验证。

限时URL及重开脚本由本任务交付文档记录；不把过期localhost链接写成常驻产品地址。原始音频仅引用本任务既有验证文件，没有另发一份音频包或音量补偿版本。
