# 设置页与 Studio 配置入口：浏览器 mock 验证

基线 14ce93714123edeb61a6e71a413882e68dd08385。阶段：个人 Beta API+Web 源码接入前的 Web 限定验证，MF-P01/P13/P18/P20/P21。只使用隔离 Vite、已有 Chromium 和合成 fixtures；所有 API 在浏览器路由层模拟，关闭 proxy、阻断外部 origin/非预期写入，不连接 Beta 端口、Docker 或真实提供商。

复用已有设置组件测试与 Studio 配置合同，浏览器补充：未配置/已配置但未测试、显式成功/鉴权失败/提供商超时/本地请求失败、pending 重复点击、离页再回来和旧响应、清除并重启后读状态的模拟、桌面及窄屏导航/Studio入口。记录请求、状态断言、截图与页面错误。清除只切换 fixture 返回值，不操作真实 Key 文件或服务；成功只证明 mock UI，不证明真实模型联调或部署。

发现确切产品缺陷时先固定反例，再做最小修复与独审；没有缺陷则交付复现脚本、验证记录与截图，不为工作量改产品。不重复 API HTTP 线或其他整站验收。

像素复核发现设置页误用“更多”展开条件；补当前主导航设置页的菜单可见性反例后，只收窄该条件，保留关于/评估页原有展开。浏览器场景最终在此单行候选复验，截图统一滚回页首后采集。

采图归零前几何证实 pathname 切换的 main.focus 会让标题被 sticky 顶栏遮住（桌面 17px / 390px约31px）。先加真实浏览器几何反例 RED，再在原 pathname effect 中 preventScroll 聚焦并滚至页首；query 不触发。补同路径 query 的滚动保持场景，jsdom 仅 stub 平台 scrollTo，物理效果以浏览器采图前断言为证。
